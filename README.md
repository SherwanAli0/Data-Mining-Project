# Diabetes Prediction using SVM and KNN

A classification project. The goal is to predict whether a patient has diabetes based on medical attributes using Support Vector Machine (SVM) and K-Nearest Neighbors (KNN) classifiers.

## Overview

This project walks through a complete machine learning pipeline:
1. **Exploratory analysis** of the Pima Indians Diabetes dataset
2. **Data cleaning** - replacing invalid zero values with column means (the means are learned from the training rows only)
3. **Feature scaling** using StandardScaler to normalize the data
4. **Class balancing** using SMOTE to handle the imbalanced dataset
5. **Model evaluation** with accuracy, precision, recall, and F1-score

## Dataset

The [Pima Indians Diabetes Database](https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database) from Kaggle contains 768 patient records with 8 medical features (glucose level, blood pressure, BMI, etc.) and a binary outcome indicating diabetes diagnosis.

The dataset is included in the `DataSet/` folder.

## Results

All stages use the same fixed 80/20 train/test split (`random_state=42`, 614 training rows and 154 test rows). The test rows are never resampled. "Original" keeps the invalid zeros as real values, "Cleaned + Scaled" fills them with training-set column means, and "After SMOTE" additionally oversamples the training rows only (614 to 802 rows).

| Model | Stage | Accuracy |
|-------|-------|----------|
| SVM | Original | 73.38% |
| SVM | Cleaned + Scaled | **75.32%** |
| SVM | After SMOTE | 73.38% |
| KNN | Original | 69.48% |
| KNN | Cleaned + Scaled | **74.68%** |
| KNN | After SMOTE | 68.18% |

After applying SMOTE, overall accuracy decreased slightly, but recall for diabetic patients was higher: SVM 58.2% to 74.5%, KNN 72.7% to 81.8% (cleaned stage to SMOTE stage, from the printed confusion matrices and the SMOTE-stage output). That means the models catch more actual positive cases, which matters more in a medical context.

These numbers come from one split with 154 test rows, so one test row is about 0.65 percentage points. There is no cross-validation, so small differences between stages should not be over-interpreted. This is a coursework exercise, not a validated clinical tool.

**Correction note (3 November 2026).** An earlier version of the script computed the imputation means over the full dataset, including the test rows, before splitting. The script now splits first and learns the means from the training rows only (`Code/preprocessing.py`). The partition is unchanged. Re-running the corrected script gives the same accuracies to four decimals. The SVM predictions are identical. For KNN, two test predictions changed in the cleaned stage (cleaned-stage KNN recall is now 72.7% instead of the 74.5% the earlier code produced) and two in the SMOTE stage, where accuracy, precision, recall and F1 came out the same. `Output/results.txt` was written by hand from the script output and was re-checked against the corrected run.

## How to Run

1. Install dependencies:
```
pip install pandas numpy scikit-learn imbalanced-learn seaborn matplotlib
```

2. Run the script from the project root:
```
python Code/DataMining_Final.py
```
The script opens plot windows. On a machine without a display, set `MPLBACKEND=Agg` first. It writes `Output/confusion_matrices.png`; `Output/results.txt` is not generated by the script.

Last checked with Python 3.11.9, pandas 3.1.0, numpy 2.4.6, scikit-learn 1.9.1, imbalanced-learn 0.14.2, seaborn 0.13.2 and matplotlib 3.11.2.

3. Run the checks (needs `pip install pytest`, no downloads):
```
python -m pytest tests -q
```
They check that the imputation means depend on the training rows only.

## Key Takeaways
- Feature scaling matters for distance-based models like SVM and KNN (every stage here is scaled, so no unscaled comparison was run)
- On this split SMOTE gave higher recall for the minority class at the cost of some overall accuracy
- Imputation, scaling and oversampling must be fitted on the training rows only, so the test rows stay unseen
- Evaluating models with precision, recall, and F1-score gives a better picture than accuracy alone
